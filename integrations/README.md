# Integrations

Small, reproducible proofs that Breakra works inside partner platforms. Each kit uses the published package (`breakra@0.2.2`) or the live hosted API, never a modified engine.

| Kit | How a partner tries it | Status |
|---|---|---|
| [Bankr](bankr/) | Two chat messages to a Bankr agent: install the skill from GitHub, check two changes via x402 ($0.04) | ✅ Verified in a real Bankr run on 2026-11-20: both verdicts and `analysis_id`s match ([findings](bankr/FINDINGS.md)) |
| [Aeon](aeon/) | Run `install-skill` with `danbuildss/breakra --path integrations/aeon`, then Run now | ✅ Verified in a real Aeon run on 2026-11-20: BLOCK/SAFE with matching `analysis_id`s; Aeon's pack-install path has gaps ([findings](aeon/FINDINGS.md)) |

[`fixtures/`](fixtures/) holds the shared contracts: `breaking` (`POST /orders` removed → `block`) and `safe` (`GET /customers` added → `safe`), with each expected result generated by the engine (`bun scripts/integration-kits.ts`). Breakra is deterministic, so any run on these contracts must return the same `analysis_id`. `tests/integrations.test.ts` keeps the kits in sync with the engine.
