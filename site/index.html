Two ways to run it

Same inputs give the same result either way: --json on the CLI prints exactly what the hosted API returns. uses filters the findings to the operations you call; Breakra doesn't read your code.

How it works

  1. 01

    Send two contracts

    The old and new OpenAPI 3.0/3.1 contract, JSON or YAML, inline, in one POST.

  2. 02

    Pay $0.02 via x402

    Check the terms, sign once. Breakra's own errors are never charged; a gateway failure is an unknown outcome, so never re-sign blindly.

  3. 03

    Act on the verdict

    safe, review or block, a semver bump, and every change with its rule, location, evidence and a recommended fix.
