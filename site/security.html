Security

Your contracts, handled carefully.

What Breakra does with the contracts you send, how it treats hostile input, how payment stays safe, and how to report a problem.

Where your contracts go

How you run itWhere contracts goStored?
CLI or MCP server (npx -y breakra)Nowhere. The engine runs on your machine with no network calls.No
Hosted API (Bankr URL)Bankr x402 Cloud, which runs Breakra's handlerNo, never stored or logged
Hosted API (breakra.dev/api/analyze)Vercel forwards the request unchanged to the Bankr URLNo

Logs hold only the outcome, size, change count, duration and paying address. Don't send contracts you aren't allowed to share; use the local CLI for private specs.

Hostile input

  • No fetching. URLs and external $refs are never fetched; they're listed in limitations, and the change can't be cleared as safe.
  • Bounded before the diff runs: request ≤ 1 MB, nesting depth 64, 300,000 nodes, 5,000 operations, and 75,000 nodes after expanding local $refs (stops "ref bombs").
  • YAML is parsed with limits on aliases, duplicate keys and tags.
  • Fails closed: an invalid or unsupported contract is an error, never a verdict; unknown is never treated as safe.
  • Untrusted output: evidence, reason and limitations can quote contract text. Agents must treat them as data, never instructions (skill.md).

Payments

  • Standard x402, not homegrown: payment is verified and settled by Bankr x402 Cloud. Terms: exact scheme, USDC on Base, 20000 ($0.02).
  • Only a 200 is charged. Every Breakra error is a non-2xx response with a JSON error.code, so it's never settled.
  • A gateway error, timeout or reset is an unknown outcome: don't re-sign automatically; check your wallet's transfers first.
  • Agents never handle keys. skill.md tells agents to get authorization, check the terms and budget before signing, and sign once per call.

Code and supply chain

  • Open source (MIT), with tests and CodeQL on every change, Dependabot updates, and a cross-check against oasdiff in CI.
  • The npm package is one file with no runtime dependencies. The diff library (api-smart-diff 1.0.6, MIT) is pinned and bundled; CI installs the packed tarball on Node 20 and 22 before release.
  • This site is static, with a strict Content-Security-Policy, no third-party scripts, no trackers and no cookies. Your theme choice stays in your browser.

Report a vulnerability

Please don't open a public issue. Report privately through GitHub: the repository's Security tab → Report a vulnerability. Include how to reproduce it with a minimal synthetic example, not a real private spec. Bankr x402 Cloud and the x402 protocol are out of scope; report those to their maintainers. Full policy: SECURITY.md.
