How it's measured

  • Sources: consecutive major versions of GitHub's REST API description (@octokit/openapi on npm, MIT) and tagged versions of Stripe's OpenAPI spec (MIT).
  • What counts as changed: a path counts as changed if it, or any schema it references, changed.
  • Sampling: for each pair, an evenly spaced sample of up to 25 changed paths, so no alphabetical slice dominates.
  • Limits: paths that exceed Breakra's limits (1 MB, 75,000 expanded nodes) are counted as skipped, never reported as safe.
  • Reproducible: results.json records each input's SHA-256.

Known limits

  • Very large APIs (Stripe) are not assessed. Every changed Stripe operation expands past 75,000 nodes once $refs are resolved. Breakra refuses such input rather than risk a timeout. Higher limits for the local CLI are a roadmap candidate.
  • oneOf/anyOf variants are compared by position, so reordered variants can be over-reported. Matching by content is a roadmap candidate.
  • Curated expectations are written by the maintainer, so they test intended behaviour. For real pairs, only hand-checked findings are claimed as correct.
